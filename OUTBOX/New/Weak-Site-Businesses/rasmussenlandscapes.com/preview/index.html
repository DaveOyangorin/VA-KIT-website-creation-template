What to do

  • Speed: 53/100 now. Compress images, lazy-load, remove unneeded scripts. Target 90+.
  • Home page has 269 words. Write 800+ useful words (services, area, process, FAQ).
  • Add a unique meta description to every page.
  • Add LocalBusiness schema with the exact name, address and phone.

  • Name South Salt Lake in the title, H1 and first paragraph of every service page.
