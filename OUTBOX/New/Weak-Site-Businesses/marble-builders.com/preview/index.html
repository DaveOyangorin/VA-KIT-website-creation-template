  • The web address shows a Bluehost "Account Suspended" page.
  • Mobile speed now: 90/100. Aim for 90+.
  • Home page words: 16. Our standard is 800+.
  • Pages in the sitemap: no sitemap.
  • Meta description: missing.
  • H1 headings on the home page: 0 (should be 1).
  • Tap-to-call phone link: no.
  • Business schema: no.
  • Pages that name Riverton: 0.

What to do

  • Get the site back up first, or rebuild it. Right now Google sends customers to a broken page.
  • Home page has 16 words. Write 800+ useful words (services, area, process, FAQ).
  • Add a unique meta description to every page.
  • Use exactly one H1 per page (home page has 0).
  • Add a tap-to-call phone link in the header.
  • Add LocalBusiness schema with the exact name, address and phone.
  • Name Riverton in the title, H1 and first paragraph of every service page.
  • Add an XML sitemap and submit it in Search Console.
