When to replace a toilet
01

Add color

WaterSense: put a few drops of food coloring in the toilet tank.

02

Don’t flush

Wait 10 minutes without using the toilet.

03

Check the bowl

If any color shows up in the bowl, the toilet is leaking from the tank.

04

Flush after

Flush right away when the test is done so the coloring doesn’t stain the tank.
