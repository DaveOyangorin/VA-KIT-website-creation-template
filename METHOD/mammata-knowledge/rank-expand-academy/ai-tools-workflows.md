## How to setup Google API

We are setting up Google's Natural Language Processor (NLP) API. Follow the steps below to set it up:

1. Follow the guide here to **enable the NLP API**: [https://docs.cloud.google.com/natural-language/docs/setup](https://docs.cloud.google.com/natural-language/docs/setup)
2. Create a Google Cloud API key to authenticate in n8n (follow the steps below)
