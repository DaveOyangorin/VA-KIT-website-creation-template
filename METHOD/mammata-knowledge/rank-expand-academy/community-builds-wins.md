### The Tool Radar

![](https://assets.skool.com/f/e0c04038afe74a28a97dccc4b03256df/c40ccfcaec634be7a9debd5d245d96c6a3ca70f32e6e409dbd473e6f4f94e170-md.png)

Every week on the calls, someone drops a tool that changes how they work. And then two weeks later someone asks in the feed, "what was that indexing tool Jesse mentioned?" and nobody can remember.

This is the fix.

The Tool Radar is a running list of every tool that has come up across 42+ community calls. Not tools we recommend for everyone. Not a curated shortlist. Just an honest record of what members are actually using, what it does, and which call it came from so you can go watch the context.

We organized it by category so you can go straight to what you need. Building sites? Hosting? Cold outreach? GBP tools? Each one is its own lesson in this folder.

A few things to know before you dig in:

- A tool being listed here doesn't mean we endorse it. Some of these are tools members mentioned once. Some are tools Jesse uses every single day. The REA context note tells you which is which.
- The HOW lives in the [Call Vault](https://www.skool.com/rank-expand-academy/classroom/9bbd4400?md=05c1b6f8e5cd47279302bd05eb72c371). This page tells you what a tool is. The calls tell you how members are actually using it to make money.
- This list grows. Every call adds something. If you spot a tool missing, drop it in the community feed and we'll add it.

Pick the category you need and go from there.

### Site Building / CMS

[**Kirby CMS**](https://getkirby.com) *(Calls 1, 6, 7, 8, 16+)*
Flat-file CMS, no database, PHP + Markdown. Fast to build, cheap to host, easy to scale. Core microsite builder for REA portfolio model. Jesse and Shawn's primary stack for years.

[**WordPress**](https://wordpress.org) *(Calls 6, 10, 42)*
CMS used by most local businesses. Plugin ecosystem, visual editing. Best choice for high-value client sites. Claude Code + WordPress is the current REA premium build stack.

[**Claude Code**](https://claude.ai/code) *(Call 42, Calls 39-41)*
Anthropic's agentic coding tool. Reads, writes, and edits files directly from a chat interface. REA's current recommendation for bespoke client sites and custom builds. Jesse: "My favourite loadout right now is WordPress + Claude Code."

[**Astro**](https://astro.build) *(Call 42)*
Static site framework. Outputs pure HTML. Used by Brian for fire station niche builds. SEO-friendly by default.

[**Replit**](https://replit.com) *(Calls 6, 11)*
Cloud-based IDE and app builder. Used early in REA for client dashboards and quick prototypes. Less favoured now vs Claude Code.

[**Duda**](https://www.duda.co) *(Call 13)*
Website builder with templates. Seth used Duda + Claude MCP to build a fully automated site pipeline.

[**Lovable**](https://lovable.dev)** / **[**Bolt**](https://bolt.new) *(Call 20)*
AI-first site builders. Community consensus: fine for landing pages, not scalable for microsite portfolios. Structurally brittle over time.

**Sonic** *(Call 42)*
Rapid design and prototype tool. Used by Blair and Shawn for client site mockups before building in Claude Code.

[**Manus**](https://manus.im) *(Call 42)*
AI agent for automated build workflows. Mark uses it with Python scripts to map EMDs, suburbs, and localities automatically at 2 sites/day pace.

### Hosting / Infrastructure

[**Kinsta**](https://kinsta.com) *(Call 42, community feed)*
Managed WordPress hosting. Server-side cron automations, strong support. Jesse's preferred host. "Never failed me." Not the cheapest.

[**Cloudflare Pages**](https://pages.cloudflare.com) *(Calls 10, 42)*
Free static site hosting. GitHub-integrated deploy. Used for HTML and Astro sites. Zero cost, fast deploy from IDE.

[**Vercel**](https://vercel.com) *(Call 42, community feed)*
Free static site hosting. GitHub-integrated. Alternative to Cloudflare Pages. Both free, both deploy from GitHub.

[**Hostinger**](https://www.hostinger.com) *(Calls 10, 42)*
Cheap WordPress hosting. Used by Shlomi and others for WP sites. Low cost, decent performance.

[**Cloudflare WAF**](https://www.cloudflare.com/waf) *(Calls 1, 6, 7, 8)*
Web application firewall. Masks origin IP, blocks bots, hides server. Used across most microsite portfolios to prevent footprint association. Free tier sufficient. Note: Cloudflare Analytics is on by default and fires before consent -- turn it off.

[**Easy Blog Networks (EBN)**](https://easyblognetworks.com) *(Call 1)*
Low-cost WP hosting at $2-3/site. Zero-footprint setup. Used in early REA days for cheap microsite portfolio hosting.

[**DigitalOcean**](https://www.digitalocean.com) *(Community feed)*
VPS and cloud hosting. Droplets from ~$7/mo. Kate runs her full n8n stack on a $7/mo droplet. Accessible via SSH from anywhere.

[**Cloudflare Email Routing**](https://www.cloudflare.com/developer-platform/email-routing) *(Calls 12, 13)*
Creates burner email addresses on any Cloudflare domain. Free. Used for GBP verification emails without paying for Google Workspace per site.

### CTR / Traffic

> Community consensus: CTR manipulation tools are dangerous for fresh microsites. Easy to sandbox a site. They work only when you already have established traffic, links, and rankings. Safer alternatives: social shares, referral traffic, Reddit, parasite pages, branded search campaigns, Pinterest or Facebook ads at $1/day.

[**CTR Booster**](https://www.ctrbooster.com) *(Call 2)*
CTR manipulation tool. Simulates user journeys from Google to target pages.

[**Kraken**](https://seovipertools.com) *(Call 2)*
Advanced CTR manipulation tool by Viper SEO Tools. More sophisticated simulation than CTR Booster.

[**Assassin**](https://agencyassassin.com) *(Call 2)*
High-end CTR tool built for scale. Expensive.

[**Microworkers**](https://www.microworkers.com) *(Call 7)*
Microtask platform. Used for CTR manipulation via human clicks rather than bots.

Philippines VA hiring platform. Shawn's preferred source for VAs. Filter hack: hide an instruction in the job description -- 80% of applicants auto-disqualify by not following it. Always run a 2-week paid trial before committing.

[**Upwork**](https://www.upwork.com) *(Calls 6, 14, 15, 16, 20)*
Freelancer marketplace with two use cases at REA: (1) hire VAs and specialists, (2) land your own SEO clients at $40-50/hr. Brian completed the full 90 Days to Freedom Upwork module and built to full-time income.
