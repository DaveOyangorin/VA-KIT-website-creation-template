**Standing GEO caveat (from OMNIUS):** most AI-visibility trackers run on **synthetic data** (scripted API prompts), so "AI visibility / share-of-citation" scores are estimates, non-deterministic, and can produce false positives. Use them for macro trend-spotting, not critical decisions. More reliable signals: LLM-indexability, post-click behavioral analytics from AI referrals, and Cloudflare AI-crawler logs.
