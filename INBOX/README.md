# INBOX

Angelo puts files here for you: audits, backlink plans, task briefs.

File names: `<client>_<job>-brief_<date>.md` — for example
`acmedental_backlinks-brief_2026-09-15.md`.

Website work also uses:
- `<client>_keywords_<date>.csv` — the real search phrases for each page (from Angelo).
- `<client>-site\` — a copy of the client's current website files, when a site already exists.

Fix notes from Angelo look like `2026-09-15_acmedental_fix_<draft>.md`. Run `/revise` on them.

A task file stays here only while that job runs. Angelo removes it when the work is approved.
Finished fix notes are moved to `INBOX\_done\` for you.

Don't edit these files. Your drafts go to `OUTBOX\`.
